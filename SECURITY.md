# Security and clinical data policy

## No PHI in GitHub

Use synthetic data only.

Never commit real patient records, names, DOBs, MRNs, addresses, claim/member identifiers, screenshots, production logs, API keys, or credentials.

## Runtime status

The current API is a synthetic-development surface. OpenAI and Google Healthcare production adapters are intentionally disabled.

Repository privacy is necessary for the intended production program but is not, by itself, a HIPAA control set. Production processing depends on the complete approved environment, access controls, vendor agreements, retention/deletion configuration, observability controls, and clinical governance.
